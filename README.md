## 💡 The Problem
Touch-typing prose is easy, but coding is fundamentally different: `{ }`, `[ ]`, `( )`, `+=`, `//`, colons, `->`, and strict indentation frequently interrupt typing flow.

**DSA Typing Master** solves this by combining **code typing drills** with **DSA pattern recognition**:
1. 📖 **Problem & Signals Tab** — Spot key recognition keywords before coding.
2. 💡 **Intuition & Logic Tab** — Interactive Q&A drill to internalize algorithmic choices.
3. 💻 **Code Typing Practice Tab** — Character-by-character validation with 4-space indentation support, live WPM, accuracy %, and synthesized mechanical keyboard sound.

---

## 🚀 Features

- **79 Curated DSA Problems** across 5 Structured Phases (Core Patterns, Trees & Linked Lists, Backtracking & Graphs, Dynamic Programming, and Advanced Patterns).
- **Tab Key = 4 Spaces Indentation** with optional Auto-Indent on Enter.
- **Synthesized Mechanical Click Audio** using Web Audio API (zero external assets, click/clack sound with mute toggle).
- **Real-Time Metrics** — WPM, accuracy %, timer, mistakes counter, and live progress bar.
- **Local Persistence** — All stats, streaks, and completed problems persist in `localStorage` without requiring a database or sign-in.
- **Dark Mode UI** — Designed with custom CSS tokens, glassmorphism, and responsive layout.

## 🚢 Deploying to Vercel (Zero-Config)

1. Push this repository to GitHub:
   ```bash
   git add .
   git commit -m "feat: complete DSA Typing Master app"
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and click **"Add New..." ➔ "Project"**.
3. Select your GitHub repository (`DSA_Typing_Master`).
4. Click **Deploy** (Vercel automatically detects Next.js).
5. Your app is live!
