## 🔒 Security, Privacy & Zero-Cost Guarantee

- **100% Free on Vercel:** Runs entirely on Vercel's **Free Hobby Tier** ($0/month forever). All pages are statically generated with 0 server compute or database costs.
- **Zero Data Leakage:** All practice progress, custom problems, typing analytics, and streaks are stored strictly inside your browser's private `localStorage`.

## 🚀 Key Features

- **85 Curated LeetCode Problems:** Comprehensive curriculum covering Arrays & Hashing, Two Pointers, Sliding Window (`#643`, `#3`, `#209`, `#567`, `#1004`, `#904`, `#424`, `#992`, `#76`), Stack, Binary Search, Linked Lists, Trees, Heaps, Graphs, and Dynamic Programming.
- **⚡ `Ctrl + K` Command Palette:** Spotlight/Raycast-style search across all 85 problems, patterns, and numbers with instant arrow-key navigation.
- **🧠 Blind Recall Mode (`Alt + B` / `Alt + H`):** Interview simulation that blurs upcoming code to test algorithmic memory, complete with a 1.5s temporary Peek button.
- **⌨️ Mechanical Switch Synthesizer:** Realistic Web Audio sound profiles (Creamy Thock, Tactile Clicky, Silent Topre) with customizable volume and zero external sound files.
- **📈 Monkeytype-Style Analytics & WPM Sparkline:** Live speed progression recording with an SVG bezier curve, Burst Peak WPM, and accuracy breakdowns.
- **📝 Custom Problem Drills (`+ Custom Drill`):** Paste any custom Python code, interview problem, or LeetCode question and drill it immediately.
- **🟩 GitHub-Style Activity Heatmap:** 20-week daily contribution grid on `/stats` tracking typing consistency and active streaks.
- **🤖 In-App AI Mentor & Docked Companion:** Integrated algorithm explanation assistant plus a popout companion launcher.
- **🎯 Smart Indentation & Auto-Pairs:** Automatically handles 4-space Python indentation, enter-line matching, and pair auto-closing (`{}`, `[]`, `()`, `""`, `''`).

1. Repository is already pushed to GitHub:

2. Go to [vercel.com](https://vercel.com) and sign in with GitHub.
3. Click **"Add New..." ➔ "Project"**.
4. Select `Devanshu777/DSA_Typing_Master` and click **Deploy**.
5. Vercel automatically deploys the static build in seconds under a free `*.vercel.app` domain with free SSL.
